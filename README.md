# 弦上曲谱

50 首经典曲目的吉他弹唱谱，纯静态网页，没有任何依赖、不需要构建。

双击 `index.html` 就能用；也可以放到任意静态托管（GitHub Pages、对象存储、Nginx）上。

---

## 有什么

**曲库**（50 首）

| 分类 | 数量 | 代表 |
| --- | --- | --- |
| 中文 · 民谣与校园 | 14 | 童年、同桌的你、那些花儿、成都、董小姐、南山南 |
| 中文 · 流行与摇滚 | 16 | 晴天、稻香、后来、十年、海阔天空、贝加尔湖畔、一生所爱 |
| 英文经典 | 12 | Hotel California、Let It Be、Wonderwall、Wish You Were Here |
| 传统（公有领域） | 5 | Scarborough Fair、Greensleeves、Amazing Grace、Auld Lang Syne、House of the Rising Sun |
| 日文 | 3 | 天空之城、千与千寻、樱花 |

**功能**

- **原调 / 谱面 / 变调夹**：三件事分开写清楚。详情页顶部直接给结论——原调是什么、谱面用哪个调指法、变调夹夹几品（不夹就写「不用夹」），下面一句话解释这个调是怎么来的。
- **六线谱**：每一句歌词上面压一格谱，两小节。六条横线是六根弦（最上面是一弦），线上的数字是按第几品，0 是空弦，绿色是根音；和弦名与指法小图标在它开始的那一拍上方。分解段照谱一根一根拨，扫弦段在谱线下方标 ↓ ↑，哪一下扫、往哪边扫都看得到。
- **变调**：±6 个半音，和弦名、指法图、六线谱里的品格数字一起变（数字按转过调的和弦重新取指法，不是把原来的数字机械加减），选择记在本机。
- **指法图**：每首自动汇总用到的和弦，六弦五品 SVG 手绘，横按自动识别。
- **自动滚动**：跟弹时页面匀速往下走，到底自动停。
- **歌词补录**：每段右侧的笔可以自己填词，存在本机浏览器，刷新不丢。
- **收藏 / 搜索 / 筛选**：按曲名、歌手、和弦名搜；按语种、风格、难度筛。
- **打印**：`⌘P` / `Ctrl+P` 直接出一份白底纸谱，工具栏和按钮不会被印上。

**快捷键**：`←` `→` 换曲 · `+` `−` 变调 · `空格` 自动滚动开关。

## 目录

```
chord_site/
├── index.html            页面骨架（顶栏 + 挂载点 + 四个脚本）
├── test/play_test.js     演奏型自检：node test/play_test.js
├── test/tab_test.js      六线谱自检：node test/tab_test.js
└── assets/
    ├── style.css         全部样式，含响应式与打印样式
    ├── chords.js         和弦引擎：解析 / 变调 / 指法图 SVG
    ├── play.js           演奏型：这一段是扫还是拨、什么节奏
    ├── tab.js            六线谱：把演奏型摊成小节/拍/弦/品并画成 SVG
    ├── songs.js          50 首曲目数据
    └── app.js            hash 路由、列表、详情、交互
```

打开顺序是 `chords.js` → `play.js` → `tab.js` → `songs.js` → `app.js`，都挂在 `window` 上，没有模块系统，直接改直接刷。

## 加一首歌

在 `assets/songs.js` 的数组里加一项：

```js
{
  id: 'my-song',            // 唯一，会出现在地址栏 #/s/my-song
  title: '歌名',
  artist: '歌手',
  key: 'C',                 // 手上按的调（不是实际音高）
  capo: 0,                  // 建议变调夹品数，0 表示不夹
  bpm: 88,
  time: '4/4',
  level: 2,                 // 1 入门 / 2 进阶 / 3 技巧
  tags: ['民谣', '中文'],    // 用于筛选，可选：中文 英文 日文 民谣 摇滚 流行 影视 传统
  tip: '一句话演奏要点，显示在谱面上方。',
  sections: [
    { n: '前奏', l: ['[C]   [G]   [Am]   [F]'] },
    { n: '主歌', l: ['[C]第一句歌词 [G]第二句歌词'] },
  ]
}
```

谱面用 ChordPro 写法：`[和弦]` 后面跟这一小节的歌词，方括号插在哪，和弦就标在哪个字上方。

- 一行里全是 `[X]`、没有歌词 → 渲染成一排和弦块（前奏、间奏用这个）。
- `n` 是段落名，随便起，会原样显示。
- 同一套和弦、反复时换词的（民谣里很常见），在段落上加 `verses: ['第二段词', '第三段词']`：
  谱子只画一遍，词按 ②③④ 码在谱子后面。原谱是把两行词叠在同一行谱下，网页排不出双行，
  叠着放只会更乱——所以分开列，标明第几段。

不需要手动登记，刷新页面就在列表里了；搜索和指法图也是从数据里现算的。

`capo` 是「谱面指法 + 夹几品 = 原调」。比如 Hotel California：`key: 'Am'`、`capo: 2`，
原调就是 Bm；页面顶部会写「原调 Bm / 谱面 Am 调指法 / 变调夹 夹 2 品」。`capo: 0` 时写「不用夹」。

### 改某首歌的右手

`assets/play.js` 顶部有两处：

- `PATTERNS`：演奏型本身。`pick` 是分解，`steps` 里 `'r'` 是根音弦、`'a'` 是五度低音、`1`-`6` 是弦号；
  `strum` 是扫弦，`D` 下扫、`U` 上扫、`null` 不扫。`per` 是每拍几格：4/4、3/4 的「一拍」
  是四分音符（2 格八分 / 4 格十六分），6/8 的「一拍」是附点四分，一格一个八分，所以 `per` 写 3。
- `BY_ID`：个别曲目的覆盖。`pick` 主歌、`strum` 副歌、`intro` 前奏间奏。
  没写进 `BY_ID` 的按拍号和难度取默认值（3/4 → `p3`，6/8 → `p6`，技巧级 → 交替低音 / 十六分扫弦）。

六线谱由「和弦指法 × 演奏型」现场算出来：一行歌词切成两小节，小节里的和弦按顺序分拍，
每个和弦再按演奏型展开成「第几拍、第几弦、第几品」。所以变调、换和弦、封闭和弦、斜杠和弦
都不会错位，品格数字也不会和和弦名对不上。

拍号决定一小节几拍：4/4 是 4 拍、3/4 是 3 拍、6/8 是 2 拍（每拍三个八分，3+3）。
按 6/8 算成 3 拍是个常见的错——刻线会落在 2+2+2 上，读出来就是三拍子的 4/4，
所以 `beatsPerBar` 对 6/8 返回 2，`p6`/`s6` 的 `per` 是 3。速度和拍速也一起标清楚：
6/8 用附点四分（`beatLabel`），不拿四分音符去对节拍器。

两处自检：

- `node test/play_test.js`：演奏型本身（哪种型配哪一段）。
- `node test/tab_test.js`：50 首 452 行逐行过一遍——每行都要出得来音、音都在合法弦品上、
  每个和弦都有指法；另外核对 C/G/Am/Em 的分解序列、扫弦一次下扫是否六根弦齐出、
  2+3+3 这类拍数分配，以及 6/8 的分组（一小节两拍、每拍三格、刻线只有一条）。

## 和弦库

指法表在 `assets/chords.js` 的 `SHAPES`，写法是六个字符对应六弦到一弦：
`x` 不弹、`0` 空弦、数字是品。比如 `C: 'x32010'`、`F: '133211'`。

表里没有的和弦会按**封闭和弦形状**自动生成（E 形、A 形），所以任何调、任何根音的 maj / m / 7 / maj7 / m7 / sus4 / 7sus4 都能出图，不必手写 12 × 7 张。

横按是根据指法推断的：最小品出现在六弦（或五弦）和一弦上、且中间每根弦都被按到，就判定为横按并画成横条。

要加新指法，直接在 `SHAPES` 里补一条，例如 `'Gm7': '353333'`。

## 关于歌词

现代作品的歌词是版权内容，内置数据里每段只标了**首句**作为定位，谱面结构和和弦进行是完整的。

每段右侧的笔可以自己把整段补全——按 `[C]歌词` 的格式写，保存后只存在你本机浏览器（`localStorage` 的 `cs_ly:<歌曲 id>:<段落序号>`），不会上传到任何地方。「恢复默认」可以撤回。

`publicDomain: true` 的 5 首传统曲目（Scarborough Fair、Greensleeves、Amazing Grace、Auld Lang Syne、House of the Rising Sun）歌词是完整的。

## 已知限制

- 六线谱是按「和弦指法 + 演奏型」推出来的，不是原版录音的逐音记谱：同一段里换和弦只换按法，
  右手型不变，每小节按型循环。真要一字不差复刻原版分解（比如指弹曲的前奏），得逐音记谱，
  现在做不到——这部分只能当「照着能弹出来」的版本，不是「官方谱」。
- 演奏型是「歌曲级」的：一首歌里同一个型会用在好几段。哪首的右手不对，在 `assets/play.js` 顶部的 `BY_ID` 里加一行覆盖即可。
- 自动滚动是匀速的，不跟节拍器速度联动。
- 没有音频播放，配合「有弦吉他」App 用。
